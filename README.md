## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## NASA Data Sources

The project is a scientific simulation; it does not currently download or ingest live NASA data. These official archives are relevant references and potential sources for future data integration:

- [NASA Exoplanet Archive — JWST Data](https://exoplanetarchive.ipac.caltech.edu/docs/JWSTMission.html) — JWST exoplanet observations and atmospheric spectra.
- [NASA Exoplanet Archive — JWST Transmission Spectra](https://exoplanetarchive.ipac.caltech.edu/cgi-bin/atmospheres/nph-firefly?atmospheres&facility=%27%JWST%%27&spec_type=%27transmission%%27) — archived transmission spectra for exoplanet atmospheres.
- [NASA Exoplanet Archive — API User Guide](https://exoplanetarchive.ipac.caltech.edu/docs/program_interfaces.html) — documentation for querying archive tables and data.
- [MAST Portal](https://mast.stsci.edu/portal/Mashup/Clients/Mast/Portal.html) —//mast.stsci.edu/portal/Mashup/Clients/Mast/Portal.html NASA-supported archive for space-telescope data, including Hubble and JWST observations.
- [MAST Portal](https://mast.stsci.edu/portal/Mashup/Clients/Mast/Portal.html) —//mast.stsci.edu/portal/Mashup/Clients/Mast/Portal.html NASA-supported archive for space-telescope data, including Hubble and JWST observations.
